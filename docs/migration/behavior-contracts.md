# Orion behavior contracts for Arduino handoff

This is the source-backed behavioral checklist for implementing note logic. It records visible defaults and explicit ranges from `circuitpython-source/src/apps/Orion`; a missing UI `minmax` means the current source does not declare a bound. Preserve behavior even where that leaves an unbounded control. All named module parameter sets are followed by inherited controls unless noted: input modules have `OCT=3`, `PADOFS=0`, `VEL=127` (velocity range 0..127), `OP` (`NEXT` default, input options `NEXT/OUT+N/ONLY`), `OUTCH=1` (1..16); processor modules have `OP=NEXT`, `SRC=PREV`, `OUTCH=1` (1..16). Common routing behavior is specified in `discovery-logic.md`.

`stop()` is a lifecycle boundary invoked for transport stop, module replacement and reset; it must silence/reset transient scheduled or held output. Except the explicitly declared `save_attrs` below, the source does not persist internal algorithm arrays. Static parameters are saved through scene `P` records.

## Fixed control slots

- SET defaults and callbacks: `KEY=C`, `SCL=1` (Major), `BPM=120` (1..300), `SWNG=0` (0..1, step .05), `TRMDE=INT`. Key/scale changes all-notes-off; mode change stops/resets clock (`circuitpython-source/src/apps/Orion/core/_modules/_set.py:10-70`).
- OUT defaults: `OUTCH=1` (1..16), `PRNT=off`; sends current arrays to MIDI and optionally prints (`circuitpython-source/src/apps/Orion/core/_modules/_output.py:6-46`).
- SETTINGS parameters are UI actions and are omitted from scene parameter persistence: scene selection/save/copy/reset, RAM print, key brightness (`circuitpython-source/src/apps/Orion/core/_modules/_settings.py`; `circuitpython-source/src/apps/Orion/core/scenes.py:25-31`).

## Exact encoder/key shortcuts

Key numbering below is physical `KEY1`..`KEY12`; source array index is physical key number (encoder=0), because keypad event `key_number` is incremented by one (`circuitpython-source/src/apps/Orion/core/input.py:24-35`). These are active only while encoder is held; without encoder, key presses are notes and start internal clock on first note if stopped (`circuitpython-source/src/apps/Orion/Orion.py:622-755`).

| Held encoder + key | Action |
|---|---|
| KEY1 | Stop transport |
| KEY2 | Start transport |
| KEY3 | Jump to input slot parameter selection |
| KEY4 | Open module selector for active chain slot |
| KEY5 | Return to chain view |
| KEY6 | Jump to output slot parameter selection |
| KEY7 | Toggle navigation mode (Notes / Parameters) |
| KEY8 | In Notes mode: octave +1. In Parameters mode: up (chain→parameter view, previous param, or increase edited value). |
| KEY9 | Toggle/advance UI action: chain→parameters, selector→leave, parameter selection→edit, editing→commit and leave. |
| KEY10 | Notes mode: pad offset -1. Parameters mode: left (previous chain/selection or decrease edited value). |
| KEY11 | Notes mode: octave -1. Parameters mode: down (next parameter / decrease edited value). |
| KEY12 | Notes mode: pad offset +1. Parameters mode: right (next chain/selection or increase edited value). |

Holding encoder ≥1000ms in chain view arms chain swap; release enters swap mode, encoder release again exits; turning encoder moves selected module slot, constrained to slots 1..6 (`circuitpython-source/src/apps/Orion/Orion.py:614-620, move_active_chain_element`, `757-792`). Any key chord consumed with encoder also calls all-notes-off on encoder release (`circuitpython-source/src/apps/Orion/Orion.py:759-764`).

## Shared acceptance and lifecycle rules

1. For every note-transform module, press/release mapping must remain balanced under repeated same-pitch inputs; use the source's `NoteRelationshipArray` or equivalent where pitch changes or fan-out occurs. Output flush sends note-offs before note-ons.
2. On transport stop, module replacement, scene reset or reboot transition, stop all module schedules and held voices, then all-notes-off. Preserve scene `P` parameter names and the `save_attrs` arrays listed above for existing user data.
3. Rate parameters are indices into `music.RATE_MIDI_TICKS`, not raw MIDI ticks. Pattern parameters index shared `music.patterns_bit/len`; all engines use transport MIDI tick and 24 PPQN timing.
4. `phraser` is a registry label only and has neither import case nor source implementation; omit from executable compatibility scope unless source is restored.
